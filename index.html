Store graphs in a PostgreSQL table through the local server. The database password stays in the server environment.

ALATARS_GRAPH_DATABASE_URL=postgresql://user:password@host:5432/database

Set this variable before starting the server, then run npm install and npm start. The table is created on first use. NocoDB can sit on top of PostgreSQL; DuckDB is a separate database engine.

Add this local MCP server to a compatible desktop AI app to list graphs, read records, and create or edit entities and connections. The AI client uses the same local or PostgreSQL storage when configured with the same database environment variable.

ChatGPT cannot connect directly to a local stdio server; it needs a remote MCP endpoint or a secure tunnel. Review AI tool permissions before allowing writes. Google Drive files must be opened or saved here; this MCP server does not use your Google token.
